# Spellwork · Temaline Valid Quilt

The **System Financial Influx Flood** is a fictional Spellwork system. Its All Recursive documents describe the source, routing rules, and Grade 45 procedure. The programs validate and simulate a local influx using whole fictional units.

## All Recursive documents

1. [Influx specification](documents/all-recursive/influx-spec.md)
2. [Valid Quilt routing and ledger](documents/all-recursive/quilt-routing.md)
3. [Grade 45 program procedure](documents/all-recursive/grade-45-procedure.md)

## Grade 45 programs

From the repository root, run with Python 3.10 or newer.

```sh
python3 programs/grade-45/validate.py programs/grade-45/example.json
python3 programs/grade-45/flood.py programs/grade-45/example.json
```
